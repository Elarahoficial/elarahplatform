# Orçamentos — Elarah

Histórico das propostas comerciais montadas para clientes.

## Experiência Hidratei — Lançamento de Produto

Proposta de ativação (colagem criativa / personalização com brilho) para
influenciadoras no lançamento da Hidratei.

Fotos usadas na proposta (em `/assets`):
- `hidrateicolagem.jpg` — foto grande da Opção 1 (colagem)
- `hidrateiadesivo.jpg` — cartela de adesivos (colagem, canto inferior esquerdo da Opção 1)
- `hidrateiadesivo1.jpg` — washi tapes (colagem, sobreposta à anterior)
- `hidrateilogo.jpg` — logo Hidratei

### Versões
- `Experiencia_Hidratei_Elarah_v6.pdf` — versão recebida (base de trabalho).
- `Experiencia_Hidratei_Elarah_v7.pdf` — **atual**. Mudança: as duas fotos
  `hidrateiadesivo` e `hidrateiadesivo1` (cartela de adesivos + washi tapes)
  na Opção 1 foram ampliadas ~22%, mantendo moldura branca, cantos
  arredondados, sombra e as inclinações originais.

O script `gerar-adesivos-maiores.py` documenta como a v7 foi gerada a partir
da v6 (requer o PDF-fonte e as imagens em `/assets`).
