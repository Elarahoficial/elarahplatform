# Calendário SEO — 12 posts long-tail (Elarah)

> **Objetivo:** capturar buscas de cauda longa de alta intenção em São Paulo e converter em reserva.
> **Estratégia:** modelo **pillar + cluster**. As 3 *foundation pages* já no ar são os pilares; cada post de blog é um satélite que ranqueia para uma busca específica e linka de volta para o pilar e para o catálogo.
> **Domínio:** elarah.com.br · **Idioma:** pt-BR · **Foco geográfico:** São Paulo (SP)

---

## 0. Como ler este calendário

Cada post tem:
- **Keyword-alvo** — a busca principal que o post quer ranquear (1 por post, sempre com "SP"/"São Paulo").
- **Intenção** — o que a pessoa quer ao buscar (informacional → comercial). Quanto mais comercial, mais perto da reserva.
- **Pilar** — qual foundation page o post reforça (link interno "para cima").
- **CTA interno** — página de catálogo/tema para onde o post empurra a conversão.
- **Ângulo** — o gancho editorial que diferencia o conteúdo.

> ⚠️ **Validar volume antes de escrever:** os volumes de cauda longa em PT-BR são baixos e variam. Depois que o Search Console estiver ativo (item 2), dá para confirmar o que já traz impressão e priorizar pelo dado real. Enquanto isso, a ordem abaixo segue **intenção comercial + sazonalidade**.

## 4. Checklist de SEO on-page por post (replicar das foundation pages)

Cada post de blog deve sair com:
- [ ] `<title>` com a keyword-alvo (≤ 60 caracteres) + "| Elarah"
- [ ] `meta description` com a keyword (≤ 155 caracteres) + chamada
- [ ] `<link rel="canonical">` com a URL própria
- [ ] `<meta name="robots" content="index, follow">`
- [ ] Open Graph (`og:title`, `og:description`, `og:image`, `og:url`)
- [ ] JSON-LD `Article` + `FAQPage` (3 perguntas reais)
- [ ] **1 H1** com a keyword · H2/H3 com variações
- [ ] Link para o **pilar** + 3–6 links internos para catálogo/categorias
- [ ] CTA WhatsApp `https://wa.me/5511914455930`
- [ ] Imagem real de `assets/` com `alt` descritivo
- [ ] Entrada no `sitemap.xml` ao publicar

> Quando formos escrever, dá pra clonar a estrutura de `date-diferente-em-sp.html` — já tem todo esse checklist pronto.
